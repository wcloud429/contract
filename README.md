# 국가·지방 계약법령 비교 서비스

국가계약법령과 지방계약법령의 **같은 주제 조항**을 **법률·시행령·시행규칙 3계층**으로 좌우 비교하고,
두 조항의 차이를 **'핵심 차이 요약'(사실 기반)** 으로 한눈에 확인하는 웹앱입니다.

> ⚖️ 이 앱은 **'비교'만** 합니다. 법률 해석·자문은 하지 않습니다(유권해석은 사람의 몫).

---

## 왜 만들었나

국가계약법령(기획재정부 소관)과 지방계약법령(행정안전부 소관)은 관장 부처가 달라,
같은 주제라도 조항을 **일일이 수작업으로 대조**해야 하는 불편이 있었습니다.
이 앱은 두 법령의 대응 조항을 자동으로 짝지어 나란히 보여주고, 정량적 차이를 요약합니다.

- **대상 사용자**: 기획재정부·행정안전부의 계약제도 담당자
- **화면 기준**: PC(데스크톱) 최적화

## 주요 기능

- **주제 선택 → 3계층 비교**: 드롭다운에서 주제를 고르면 법률·시행령·시행규칙 3계층이 한 화면에, 계층마다 **좌=국가 / 우=지방**으로 고정 비교.
- **핵심 차이 요약**: 주제별로 정량 차이를 표로 대조.
  - 제재 주제(입찰참가자격 제한·과징금·지체상금): 행위/사유/계약종류별 **제재기간·부과율·요율**.
  - 보증금 주제(입찰보증금·계약보증금): **요율·납부수단·면제/대상**(준용·표기 정규화로 허위 차이 방지).
  - 대조 표 제목에 **"차이 N건" 배지**로 차이 규모를 즉시 표시.
- **별표 표시**: 조문이 참조하는 별표(제한기준표·과징금 부과기준표 등)를 접이식으로 함께 표시.
- **동향 살펴보기**: 주제별 관련 조문 안내 + 법제처·국회 의안정보시스템·국민참여입법센터 **공식 출처 링크**(새 탭). 실시간 자동 수집이 아닌 큐레이션 링크.
- **배지**: 두 조문이 완전히 같으면 "차이 없음", 한쪽만 있으면 "해당 조항 없음".

## 비교 주제 (5개)

입찰참가자격 제한 · 과징금 · 지체상금(지연배상금) · 입찰보증금 · 계약보증금

## 기술 스택

- **순수 프론트엔드**: `index.html`(HTML + CSS + 바닐라 JS). 프레임워크·빌드·패키지 매니저 **없음**.
- **의존성 없음**: 외부 라이브러리·CDN·npm 패키지 없음. diff(LCS) 로직도 직접 구현.
- **빌드타임 데이터 수집**: `fetch-laws.js`(Node)가 법제처 API로 조문+별표를 수집해 `data.json` 생성.

## 구성 파일

| 파일 | 설명 |
|------|------|
| `index.html` | 비교 화면. `data.json`을 `fetch`해 렌더링. |
| `data.json` | 법령 조문 데이터(3계층 중첩 구조). **공개 조문만** 담김(키 없음). |
| `fetch-laws.js` | 법제처 OpenAPI 수집 스크립트. `.env`의 키로 6개 법령을 수집 → `data.json` 생성. |
| `serve.js` | 로컬 확인용 정적 서버(포트 8000, `.env` 서빙 차단). |
| `build-dist.js` | 배포용 `dist/`(index.html + data.json만) 생성 스크립트. |
| `vercel.json` | Vercel 배포 설정(빌드=`build-dist.js`, 출력=`dist/`, 보안 헤더). |

## 로컬에서 실행

`index.html`이 `data.json`을 `fetch`하므로 **file:// 더블클릭이 아니라 로컬 서버로 열어야** 실데이터가 보입니다.

```bash
node serve.js
# 브라우저에서 http://127.0.0.1:8000/ 접속
```

## 법령 데이터 갱신

법제처 API 인증키(OC)를 발급받아 `.env`에 넣고 수집 스크립트를 실행합니다.

```bash
# .env.example 을 복사해 .env 를 만들고 LAW_API_OC 값을 채운다
node fetch-laws.js   # data.json 재생성
```

> `.env`는 `.gitignore`로 보호되며 **절대 커밋하지 않습니다.** `data.json`에는 공개 조문만 담기고 키는 포함되지 않습니다.

## 배포 (Vercel)

정적 사이트로 배포합니다. `vercel.json`이 `node build-dist.js`로 **`dist/`(index.html + data.json)만** 빌드·서빙하므로,
`.env`·수집 스크립트 등 나머지 파일은 공개되지 않습니다.

- 빌드 명령: `node build-dist.js` · 출력 디렉터리: `dist/`
- 런타임에 법제처 API를 호출하지 않으므로 **Vercel 환경 변수(키) 등록 불필요.**

## 데이터 출처 및 면책

- 조문·별표는 **법제처(국가법령정보 공동활용) OpenAPI**의 **공개 정보**입니다.
- 개인정보를 수집·저장·처리하지 않습니다.
- 핵심 차이 요약은 **문구·수치의 기계적 대조 결과**이며 **법적 해석이 아닙니다.** 정확한 맥락은 항상 원문·별표를 확인하세요.

## 비범위 (만들지 않음)

- AI 자동 유권해석·법률 자문
- 회원가입·로그인 등 계정 시스템
